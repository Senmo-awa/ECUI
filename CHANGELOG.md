# Changelog

## 1.0.0 — 2026-11-24

First public release.

### UI

- `/home` and `/warp` now open a server-side UI instead of printing a chat list.
- Two backends:
  - vanilla server dialogs (`MultiActionDialog`) on 1.21.6+ / 26.x;
  - a chest-style inventory UI that detects a selection when the player takes the marker item.
- `uiMode` config: `auto` / `dialog` / `inventory`; automatic fallback to inventory when the
  dialog API is unavailable or a dialog fails to build.
- Inventory pages for large home/warp lists.
- Admin nearby-home search (`/homesnear`, `/nearbyhomes`) works in both backends.

### Localization

- Added `zh_cn` and `en_us` language files.
- All server-sent strings are resolved through the language bundle.
- `language: auto` follows each player's client language; `zh_cn` / `en_us` can force it.

### Configuration

- `config/ec_ui.json` now also controls `uiMode`, `fallbackToInventory`, `checkHomePermission`,
  `checkWarpPermission`, and `inventoryRows`.
- `/ecui reload` reloads config and logs the language bundle status.

### Compatibility

- Builds for Minecraft 26.3 (EC 0.42.x), 26.2 (EC 0.41.x / 0.42.0-mc26.2), and
  26.1.1 (EC 0.39.x).
- EC command nodes, permissions, suggestions, cooldowns and teleport delays are preserved.
- Dialog-specific classes are isolated so a build without the dialog API can still start.

### Fixes carried from beta

- Avoids EC 0.42's `IdentifierException` in the `/warp` UI and tab completion for warp permission
  names containing uppercase letters.
- Soft-fails the Brigadier reflection hooks instead of throwing during static initialization.

### Assets

- New 512×512 icon: white pixel `EC` / `UI` on saturated blue, generated by `tools/make_icon.py`.
- Real in-game screenshots in `docs/screenshots/` (26.3 client, server-side install, GUI scale 2).

### Known issues

- EC's own `/warp <name>` / `/warp tp <name>` still fail on 26.3 for warps whose permission name
  contains uppercase letters (upstream EC defect; PR #408).
- 26.2 and 26.1.1 builds compile against their matching EC jars but were not started on a
  separate local server in this release.
